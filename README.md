# Rekapan Retribusi UPT Trans

Aplikasi Android offline untuk pencatatan pendapatan jasa kepelabuhanan tahun 2026.

## Jenis retribusi
1. Jasa Parkir
2. Jasa Pelabuhan Sri Siantan
3. Jasa Pelabuhan Padang Melang (Jemaja)
4. Jasa Pelabuhan Antang
5. Jasa Pelabuhan Kampung Baru
6. Jasa Pelabuhan Roro Matak
7. Jasa Tambat Pelabuhan Roro Matak

## Fitur yang direncanakan
- Dashboard hanya menampilkan total gabungan tujuh retribusi.
- Setiap kategori memiliki rekap harian, bulanan, tahunan, dan riwayat.
- Input, edit, hapus; satu transaksi per kategori per tanggal.
- Laporan PDF A4.
- Backup dan pemulihan JSON.
- SQLite lokal dan penggunaan offline.

## Build
Buka Actions dan jalankan workflow Build Rekapan Retribusi UPT Trans. APK debug akan diunggah sebagai artifact jika build berhasil.
